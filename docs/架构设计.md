# 社区快递驿站包裹管理系统 - 架构设计

## 一、系统架构

本系统采用前后端分离的三层架构：
- 表现层：微信小程序（用户端）、Web管理后台（驿站端/管理员端）
- 业务逻辑层：后端服务，提供RESTful API接口
- 数据访问层：MySQL数据库，存储包裹、用户、订单等数据

## 二、技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端 | 微信小程序 | 用户端包裹查询、取件码接收 |
| 前端 | Vue.js + Element UI | 驿站管理端、管理员后台 |
| 后端 | Spring Boot | 微服务框架 |
| 数据库 | MySQL 8.0 | 关系型数据库 |
| 缓存 | Redis | 取件码缓存、热点数据 |
| 消息队列 | RabbitMQ | 短信通知异步发送 |

## 三、模块划分

1. 用户模块：用户注册、登录、信息管理
2. 包裹模块：包裹入库、出库、库存查询
3. 通知模块：短信通知、微信推送
4. 统计模块：数据统计、报表生成
5. 系统模块：权限管理、日志管理

## 四、核心接口

- POST /api/package/入库 - 包裹扫码入库
- POST /api/package/出库 - 取件码出库
- GET /api/package/list - 查询包裹列表
- GET /api/package/{id} - 查询包裹详情
